# Lamp 产品需求文档（PRD）

本文记录产品定位、当前实现与待讨论方向，不分配功能版本、发布日期或交付顺序。能力状态以当前仓库代码为依据，不代表所有平台均已通过端到端验证。

## 产品定位

Lamp 是面向小说与长文创作者的本地优先桌面编辑器。首先保证打开、编辑、保存、关闭和恢复文稿的主流程可靠，再通过插件补充写作反馈与可选 AI 辅助。

目标用户是需要组织多个文稿、持续写作和低干扰编辑环境的作者。AI 是可选工具，不是使用编辑器的前提。

## 产品原则

- **文稿优先**：保存失败、外部修改和退出取消不能被当作成功处理。
- **本地优先**：文稿直接存于本地文件，基础创作不依赖账号或网络。
- **减少干扰**：常用操作清晰直接，设置与进度反馈不打断写作。
- **反馈有意义**：统计服务于作者的体验与成就感，不以防作弊为目标，也不宣称精确衡量劳动量。
- **插件独立**：插件拥有自己的代码、设置与翻译，通过宿主 API 和贡献点接入，内建插件也遵循同样边界。
- **如实表达能力**：区分已接入界面的功能、底层接口和待讨论需求，不把类型定义或构建配置等同于交付完成。

## 当前能力

| 模块 | 已有实现 | 边界与说明 |
| --- | --- | --- |
| 编辑 | TipTap 富文本、格式工具栏、撤销重做、段落专注模式 | 不是 Markdown 源码编辑器；未提供完整 Zen 或打字机模式 |
| 文档 | 新建、打开、多标签页、保存、另存为、关闭时处理未保存修改 | 单文件可独立编辑，不要求先打开工作区 |
| 文件格式 | `.lmph`、`.md`、`.html`、`.txt` 读写与另存为 | 富文本与文本格式转换不保证保留任意源文件语法、排版或全部 HTML 元素；未实现 ePub/PDF 导出 |
| 保存与恢复 | 原子写入、保存期间编辑状态保护、外部内容变更确认、自动保存恢复副本、启动恢复对话框 | 外部变更可取消或确认覆盖，没有自动合并与历史版本浏览；恢复副本不是备份系统 |
| 工作区 | 文件夹工作区、文件树、文件监听、打开与关闭工作区 | 当前窗口管理一个工作区；没有卷/部/章等专用项目模型 |
| 最近入口 | 启动页最近文件、记忆上次工作区、按设置恢复上次工作区 | 没有持久化的多工作区最近列表界面 |
| 查找替换 | 当前文档和工作区查找替换、大小写与全词选项 | 没有正则搜索、搜索历史或持久化增量索引 |
| 快捷操作 | 命令面板、快捷键录制、自定义、冲突检测与重置 | 快捷键覆盖范围取决于已注册命令 |
| 写作统计 | 当前文档字数/字符数、会话与每日增量、目标、连续写作天数、近 28 天热力图和达标动效 | 由 `lamp.writing-stats` 提供；不扫描整个工作区统计作品总字数 |
| AI 辅助 | 润色、扩写、续写、总结，提示词设置，接受或拒绝建议 | 按需调用配置的服务商；没有项目知识库、长期记忆或分析缓存 |
| 外观与语言 | 浅色/深色/跟随系统主题，中文和英文资源 | 仍有硬编码界面文字，不能宣称全部文案已国际化 |
| 插件 | 三个内建插件、用户/工作区 ESM 插件加载、贡献注册、独立翻译与设置 | 设置页展示已加载插件，不提供完整启停、安装或商店流程；其他限制见[插件指南](PLUGIN_SYSTEM.md) |
| 状态栏 | 工作区信息、插件统计文本与点击操作 | 行列显示尚未绑定光标位置，不能作为实时行列信息；UTF-8 标签不代表编码检测能力 |

主要实现入口：[应用流程](../src/App.vue)、[编辑器](../src/components/Editor.vue)、[工作区流程](../src/composables/workspaceExplorerMethods.js)、[Rust 后端](../src-tauri/src/lib.rs)、[写作统计](../src/builtins/writing-stats/index.ts)。

### 文件与恢复语义

- `.lmph` 保存 HTML 内容；`.html` 也按 HTML 内容处理，不是完整网页编辑器。
- Markdown 打开时转换为编辑器内容，保存时使用 TipTap Markdown 序列化。编辑器规范化与用户修改分开记录，避免仅打开文件就出现未保存提示。
- 纯文本打开时进行 HTML 转义，保存时转换回文本；富文本格式不能保留在 `.txt` 中。
- 自动保存写入应用数据目录的恢复副本，不等同于定期覆盖原文件。
- 普通保存会基于已读取的磁盘内容检查外部变化；另存为和插件直接写文件不具备同一套文档级冲突处理。

相关逻辑与回归测试见 [documentDirtyState.js](../src/lib/documentDirtyState.js)、[documentFormats.js](../src/lib/documentFormats.js) 和 [scripts/regression](../scripts/regression)。

### 写作统计口径

- 按约 1.5 秒间隔采样当前编辑器文本；支持范围内的汉字逐字计数，其他文字按词组统计，另提供去空白字符数。
- 每次采样只累计相对上次采样的正向增长。删除不扣除已累计进度，粘贴或 AI 插入也可能计入增长。
- 切换文档时重建基线，已有内容不直接计入当天新增量。
- 日期使用本地时间，历史与每日目标保存在插件存储中；会话计数在插件初始化时重置。
- 这是近似的创作反馈，不是净稿字数、键盘输入计数或跨设备同步记录。

统计规则以 [logic.js](../src/builtins/writing-stats/logic.js) 和 [state.ts](../src/builtins/writing-stats/state.ts) 为准。

## 数据与隐私

| 数据 | 当前存放位置与行为 |
| --- | --- |
| 文稿 | 用户选择的本地路径 |
| 自动保存恢复副本 | Tauri 应用数据目录下的 `autosave/`，文件后缀为 `.autosave` |
| 通用、编辑器与 AI 设置 | Tauri 应用数据目录下的 `config.json`；首次使用时从可执行文件旁、其次从启动工作目录迁移旧配置，保留原文件；之后不再依赖启动目录 |
| 最近文件、上次工作区、侧栏偏好 | WebView 的 `localStorage` |
| 插件设置与统计历史 | 按插件 ID 隔离的 `localStorage`，由宿主存储服务管理 |
| 快捷键覆盖 | WebView 的 `localStorage` |
| 外部插件 | 工作区的 `.lamp/plugins/` 或 Tauri 应用数据目录的 `plugins/` |

AI 请求会将相关文本发送到用户配置的服务商。API Key 在设置界面使用密码输入框，但当前配置文件是明文 JSON，不是系统凭据库。插件运行在同一 WebView 中，能力声明并非安全沙箱，应只加载可信插件。

仓库没有实现 `.lamp/project.json`、`.lamp/export-config.json` 或 `.lamp/analysis.json` 数据协议，不能将这些曾提出的路径作为现有配置说明。

## 待讨论方向

以下是尚未确定范围和顺序的候选需求，不代表交付承诺。设计时应先确认用户需求，并优先利用现有插件边界。

- 作品级统计、章节分组、项目概览与模板。
- ePub/PDF、批量导出与导出预设。
- 正则搜索、搜索历史与大型工作区索引。
- 分割视图、标签页分组与拖拽排序。
- 历史快照浏览、差异比较与合并。
- 人物和世界观资料、大纲、项目上下文与 AI 提示词管理。
- 编辑器字体与行距设置、打字机模式和更完整的专注体验。
- 片段、批注与按需语言检查。
- 插件安装、启停、依赖管理、接口补全与信任机制。
- 完整国际化、可访问性与跨平台交互打磨。
- 分享、协同与多窗口模型需要另行讨论，不作为当前能力宣传。

## 工程现状

- 前端使用 Vue 3、Vite、Pinia、TipTap、Reka UI 和 Tailwind CSS，代码包含 JavaScript、TypeScript 与 Vue 单文件组件。
- Node.js 回归测试覆盖文件/状态、统计与插件生命周期；Rust 测试覆盖配置迁移与原子写入。Playwright 使用真实 Vue/TipTap 和模拟桌面桥接验证文档流程；Windows 安装包测试验证真实 IPC、设置跨启动目录持久化与崩溃恢复。
- [CI](../.github/workflows/ci.yml) 在 `main`、`develop` 的推送与 PR 上执行前端版本检查、lint、测试、构建、浏览器文档回归、Windows 隔离安装包测试，以及 Rust 格式、Clippy 与测试。尚不包含 macOS/Linux 安装后 UI 自动化。
- [Release 工作流](../.github/workflows/release.yml) 配置了 Windows、macOS、Linux 各 x64/arm64 构建。匹配应用版本的 tag 触发草稿 Release；普通分支推送不构建安装包。
- 当前工作流没有配置应用签名、公证或自动更新发布。六个平台目标的实际构建结果应查看对应 Actions 记录，不能由矩阵配置推断全部通过。
- 应用版本以 [package.json](../package.json)、[Cargo.toml](../src-tauri/Cargo.toml)、[Cargo.lock](../src-tauri/Cargo.lock) 和 [tauri.conf.json](../src-tauri/tauri.conf.json) 为准，由 `pnpm run version:check` 检查一致性；插件 API 和插件自身版本独立维护。

运行与构建命令见[中文 README](README_zh-CN.md)，工程协作约定见[开发指南](../CLAUDE.md)。
